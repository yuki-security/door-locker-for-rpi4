# 🔑 ドアロックくん (SwitchBot LINE Bot)

LINE BotとSwitchBotスマートロックを連携させ、LINEのトーク画面や専用QRコードから安全に鍵の解錠・施錠を行うスマートホームシステムです。

---

## 🌟 主な機能

* **LINEからの鍵操作:** 「開けて」「閉めて」のメッセージで鍵を操作。
* **管理者承認機能:** 初回ユーザーからの利用申請に対し、管理者のLINEから「永久承認」「2時間限定」「日時指定」で許可を付与。
* **ワンタイムQRコード認証:** 30分ごとに自動更新されるQRコード（`/qr`）を使った安全な利用申請。
* **セキュリティロックアウト:** 無効なキーを3回連続入力したユーザーを15分間自動ブロック。
* **Webダッシュボード:** リアルタイムログ確認（`/logs`）およびQRコード表示。
* **温湿度連携:** 「室温」メッセージでお部屋の温度・湿度を表示。
* **物理操作検知:** 顔認証パッドや手動による鍵操作を検知し、管理者へ通知・ログ記録。

---

## 🛠 動作環境

* Python 3.9 以上
* Raspberry Pi / Linux サーバー
* SwitchBot Smart Lock & ハブミニ
* ngrok (固定ドメイン推奨)
* LINE Messaging API アカウント
